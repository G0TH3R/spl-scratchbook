# Changelog

All notable SPL Scratchbook changes are recorded here.

## 1.0.2

- Collapse an entire Search Cell into a compact SPL-preview row.
- Restore editor, controls, status, and retained results with Expand Cell.
- Preserve automatic SPL formatting, time presets, risk guards, and browser-state migration.

## 1.0.1

- Add quote- and triple-backtick-comment-aware risky-command confirmation.
- Complete the Splunk safeguard-command set.
- Settle explicit and backend-originated cancellation correctly.
- Scope callbacks to the active search generation.
- Snapshot cell IDs for Run all.
- Remove the fixed result-fetch timeout that could discard delayed results.
- Suppress the redundant generated dashboard header.

## 1.0.0

- Initial standalone SPL Scratchbook identity.
- Add stacked Search Cells, inline table results, time presets, collapse controls, keyboard shortcuts, browser persistence, and automatic SPL formatting.
